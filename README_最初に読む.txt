daynote v10 — iPhoneホーム画面用PWA

このフォルダをHTTPS対応の静的ホスティング（例: GitHub Pages）にそのまま公開します。
公開先のルートに index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png が必要です。

今回の更新
- 月別OCR候補にTesseractの信頼度を表示。
- 信頼度65%未満の候補を黄色で目立たせ、要確認に。
- 手動で勤務を選び直すと「手動確認済み」と表示。
- OCRの信頼度は正解率ではありません。高い値でも全日を紙の表と照合してください。

シフト表読み取りの制約
- 写真上でD班の数字・丸印の行を1か月分だけ囲みます。日付行や班名を含めず、1日目から月末までが範囲に入るようにします。
- セル幅が均等でない、斜め撮影、罫線がセル内に重なる場合は日付との対応がずれる可能性があります。
- 1日ずつ分割するOCRは仮候補を作る機能で、年間全日程の完全自動登録ではありません。
- ○（休日）と●（一斉休日）、数字1/2/3は必ず元写真で確認してから登録してください。

公開方法の概要
1. GitHubにサインインし、Publicリポジトリを新規作成。
2. このフォルダ内のファイルをリポジトリのルートにアップロード。
3. Settings > Pages > Deploy from a branch > main / root を選択して保存。
4. 公開URLをiPhoneのSafariで開き、共有 > ホーム画面に追加。

プライバシー・データ
- シフト、ToDo、日記は同じブラウザのlocalStorageに保存されます。Safariのサイトデータ削除等で消える可能性があるため、バックアップを書き出してください。
- 写真はアプリのサーバーに送信しない設計ですが、OCRライブラリは初回にCDNから取得します。
- Publicリポジトリのソースは誰でも閲覧できます。個人情報をコードやリポジトリに入れないでください。

この環境からユーザーのGitHubアカウントを操作したり、公開URLを発行したりはできません。


【年間シフトCSVの取り込み（v11）】
1. daynoteを開き、「年間シフトCSVを取り込む」でCSVファイルを選ぶ。
2. 「CSVを読み込む」を押す。
3. 365日分の候補が確認表に表示される。
4. 元の年間表と照合し、勤務記号を必要に応じて修正する。
5. 「カレンダーに登録」を押す。空欄は上書きしない。

注意：付属の「daynote_D班_2026_年間シフト_完成候補_v12.csv」は写真からの転記候補であり、365日すべての正確性を検証済みではありません。勤務表と照合してから登録してください。CSV取り込みはデータを自動で確定する機能ではありません。
